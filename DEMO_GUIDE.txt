first request). To warm it up, open a second browser tab and hit:
  http://localhost:8000/ai/search?q=test
(with a valid auth token) — or just use the dashboard search after login.

TECH STACK — WHAT AND WHY
================================================================================

FRONTEND:
---------------------------------------------------------------------------
| Technology        | Version | Used For                                  |
---------------------------------------------------------------------------
| React             | 18.3    | UI component library — builds the entire  |
|                   |         | single-page application (SPA)             |
| Vite              | 5.4     | Build tool & dev server — fast hot module  |
|                   |         | replacement (HMR) during development      |
| React Router DOM  | 6.26    | Client-side routing — handles page         |
|                   |         | navigation without full page reloads      |
| Axios             | 1.7     | HTTP client — makes API calls to the       |
|                   |         | FastAPI backend with JWT auth headers     |
| React Icons (Fi)  | 5.7     | Icon library — sidebar and UI icons        |
|                   |         | (Feather icon set)                        |
---------------------------------------------------------------------------

BACKEND:
---------------------------------------------------------------------------
| Technology        | Version | Used For                                  |
---------------------------------------------------------------------------
| FastAPI           | 0.115   | Web framework — handles all REST API       |
|                   |         | endpoints, request validation, CORS       |
| SQLAlchemy        | 2.0     | ORM (Object-Relational Mapper) — maps      |
|                   |         | Python classes to database tables          |
| SQLite            | built-in| Database — stores all application data     |
|                   |         | (users, profiles, tasks, diary, etc.)     |
| Uvicorn           | 0.30    | ASGI server — runs the FastAPI application |
|                   |         | with async support and hot reload         |
| Python-Jose       | 3.3     | JWT (JSON Web Tokens) — generates and      |
|                   |         | verifies authentication tokens            |
| bcrypt            | 4.2     | Password hashing — securely stores         |
|                   |         | passwords (one-way hash, not encryption)  |
| Pydantic          | 2.x     | Data validation — validates request/       |
|                   |         | response schemas automatically            |
---------------------------------------------------------------------------

AI / ML:
---------------------------------------------------------------------------
| Technology          | Version | Used For                                |
---------------------------------------------------------------------------
| scikit-learn        | 1.3+    | ML framework — TF-IDF vectorizer,       |
|                     |         | Logistic Regression (intent classifier, |
|                     |         | workload predictor), cosine similarity  |
| Sentence-           | 2.2+    | Semantic search — encodes text into      |
|   Transformers      |         | 384-dim vectors using all-MiniLM-L6-v2  |
|                     |         | (pre-trained transformer model, 22M     |
|                     |         | parameters)                             |
| FAISS (faiss-cpu)   | 1.7+    | Vector similarity search — Facebook AI   |
|                     |         | library for fast nearest-neighbor lookup |
|                     |         | on embedding vectors                    |
| TextBlob            | 0.18+   | Sentiment analysis — rule-based NLP for  |
|                     |         | polarity (-1 to +1) and subjectivity    |
|                     |         | scoring of diary entries                |
| NumPy               | 1.24+   | Numerical computing — array operations   |
|                     |         | for ML feature vectors and scoring      |
---------------------------------------------------------------------------

WHICH AI/ML ALGORITHM IS USED WHERE:
---------------------------------------------------------------------------
| Feature                  | Algorithm                                   |
---------------------------------------------------------------------------
| Semantic Search          | Sentence-Transformers + FAISS cosine sim     |
| Intent Classification    | TF-IDF + Logistic Regression                |
| Sentiment Analysis       | TextBlob (rule-based + pattern-based NLP)   |
| Performance Scoring      | Weighted multi-factor formula (5 factors)   |
| Workload Prediction      | Logistic Regression (6 features)            |
| Report Summarization     | TF-IDF + Cosine Similarity (extractive)     |
| Auto Diary-to-Report     | TF-IDF Summarizer pipeline                  |
| Senior Intern Tips       | Rating ranking + TF-IDF keyword extraction  |
